# API Dehash

API Dehash is a malware analysis tool that helps identify Windows API functions hidden through API hashing. It recovers the original Windows API names from hashed references, providing valuable insight into a program’s behavior and functionality.

## API Hashing

API hashing is a technique commonly encountered during malware analysis.
Instead of storing Windows API names directly, a program can store a
hash derived from the API name and resolve it at runtime.

For example:

```text
CreateFileW
VirtualAlloc
LoadLibraryA
```

may be represented by their corresponding hash values within a binary.

API Dehash compares these hashes against a database of known Windows API
functions to recover their original names.

## Usage
ApiDehash `<COMMAND>` [OPTIONS]

### Commands
```text
scan - Extract candidates from an executable and compare them against APIs
file - Generate and save a hash lookup table to hashes.csv
help - Print this message or the help of the given subcommand(s)
```

### Options
```text
--syswhispers2 <SEED>  SysWhispers2 seed (decimal or hexadecimal)
--djb2 <SEED>          DJB2 seed (decimal or hexadecimal)
--apis <FILE>          Custom API list, one API name per line (default: built-in list)
-h, --help             Print help
-V, --version          Print version
```

### Examples
```text
Display help:
ApiDehash --help
```

```text
Scan an executable using DJB2:
ApiDehash scan malware.exe --djb2 0x12345678
```

```text
Scan an executable using SysWhispers2:
ApiDehash scan malware.exe --syswhispers2 0x12345678
```

```text
Scan an executable using multiple algorithms:
ApiDehash scan malware.exe --syswhispers2 0x12345678 --djb2 0x12345678
```

```text
Scan using a custom API list (e.g. the large list generated by apis.py):
ApiDehash scan malware.exe --djb2 0x12345678 --apis apis.txt
```

```text
Create a hash table for manual lookup using the algorithm DJB2:
ApiDehash file --djb2 0x12345678
```

```text
Create a hash table for manual lookup using the algorithm SysWhispers2:
ApiDehash file --syswhispers2 0x12345678
```

```text
Create a hash table for manual lookup using multiple algorithms:
ApiDehash file --syswhispers2 0x12345678 --djb2 0x12345678
```

## Development

### Requirements

- Rust
- Cargo
- Python (Optional, for generating a custom api list)

### Clone the repository

```bash
git clone https://github.com/gustavvising/ApiDehash.git
cd ApiDehash
```

### Build

```bash
cargo build --release
```

Output:

```bash
target/release/ApiDehash
```
